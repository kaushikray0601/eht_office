## 1. Module Scope and Module Boundary

### What this module does
The cold cable sizing module sizes the upstream electrical conductors (cold cables)
that feed the heat tracing system from the distribution board (DB) or motor control
centre (MCC) to the field junction boxes and heating cable cold-end connections.

The module consumes the stabilised SR/MI hot-engineering output. It does NOT
recalculate heat loss, re-select heating cables, or modify the hot-engineering
topology.

### What this module does NOT touch
- Heat loss calculation (owned by `ProcessLineCalculation` / `HeatLoss`)
- Tracer selection (owned by `SelectedTracer` / `SelectedMIHeater`)
- Breaker sizing for heating circuits (owned by `PowerDistribution`)
- SR/MI SLD topology (generated by `compute_power_distribution`)
- Any SR catalogue coefficients or MI catalogue records

### Module ownership boundary (data)
| Owned by hot-engineering (read-only for this module) | Owned by cold-cable module |
|---|---|
| `PowerDistribution`, `PowerDistributionBranch` | `ColdCableCatalogue` |
| `ProcessLineCalculation` | `ColdCableResult` (one per feeder segment) |
| `SelectedTracer`, `SelectedMIHeater` | New `ProjectData` fields for cold cable |
| `HeatLoss`, `BOQ` | Updated cable schedule with sized cold cable data |
| `SLDTopologyEdit`, `CableScheduleOverride` | Updated SLD with sized cable annotations |

## 5. Calculation Method — Precise Engineering Formulas

### Step 1 — Resolve Active Cable Lengths

Call a single function `resolve_cable_lengths(branch, project)` that returns the
active length for each cable component. Resolution order:

1. If a `CableScheduleOverride` with `is_active=True` and `manual_length_m` is not
   None exists for the `Cable4C` or `Cable3C` component tag: use `manual_length_m`.
2. If an applied `SLDTopologyEdit` exists and the edited cable-schedule row for this
   component has an explicit length: use that length.
3. Use `PowerDistributionBranch.cable_length_db_to_jb` (4C) or
   `cable_length_jb_to_jb` (3C) as the project-default fallback.

Record the source in `ColdCableResult.length_basis`:
`'manual_override'`, `'topology_edit'`, or `'project_default'`.

If the resolved length is zero or None: set `sizing_status = 'length_missing'` and
abort this branch. Do not attempt sizing.

### Step 2 — Identify Required Current

```
I_phase_4C = per_circuit_operating_current_a   # balanced loading assumption
I_phase_3C = per_circuit_operating_current_a   # per-circuit current for 3C cable

NOTE: Use operating current, not starting/maximum current, for ampacity and VD
sizing. The starting current is transient and sizing for it would be uneconomical.
The MCB is already selected to handle the starting current. The cold cable is
sized for sustained operating current.
```

### Step 3 — Temperature Derating Factor (auto-calculated)

The catalogue ampacity is published at `ampacity_temp_ref_c` (typically 30°C).
Correct for the site maximum ambient temperature `T_site = ProjectData.max_amb_t`:

```
K_temp = sqrt((T_max_conductor - T_site) / (T_max_conductor - T_ref_catalogue))

Where:
  T_max_conductor = ColdCableCatalogue.max_conductor_temp_c (e.g. 90°C for XLPE)
  T_site = ProjectData.max_amb_t
  T_ref_catalogue = ColdCableCatalogue.ampacity_temp_ref_c (e.g. 30°C)

Example: XLPE (90°C), site 40°C, reference 30°C:
  K_temp = sqrt((90 - 40) / (90 - 30)) = sqrt(50/60) = 0.913
```

If `T_site >= T_max_conductor`: reject configuration — cable is thermally unsuitable
for site ambient. Set `sizing_status = 'unsizeable'`.

### Step 4 — Available Ampacity After Derating

```
K_group = ProjectData.cable_grouping_derating  (user-entered, range [0.1, 1.0])
K_total = K_temp × K_group

Available_ampacity_A = ColdCableCatalogue.ampacity_a × K_total
```

### Step 5 — Candidate Cable Sizes (Ampacity Gate)

For each cable component (4C and 3C), filter the catalogue to find all rows where:
- `conductor_material` = project `cable_conductor_material`
- `insulation_type` = project `cable_insulation_type`
- `installation_method` = project `cable_install_method`
- `is_validated = True`
- For 4C: `core_count = 4`
- For 3C: `core_count = 3`

Sort by `conductor_size_mm2` ascending.

For each candidate row, calculate available ampacity after derating. The minimum
qualifying ampacity is:
```
4C: Available_ampacity ≥ I_phase_4C × safety_margin
3C: Available_ampacity ≥ I_phase_3C × safety_margin
```

Where `safety_margin = 1.0` for first pass (the MCB loading restriction already
embeds a margin from the hot-engineering side).

Apply project minimum cable size filter: if `min_cold_cable_size_mm2 != 'CALCULATED'`,
eliminate any candidate rows with `conductor_size_mm2 < float(min_cold_cable_size_mm2)`.

Candidates that pass the ampacity gate are the eligible set for VD checking.

### Step 6 — Voltage Drop Calculation (PF = 1.0, sin φ = 0)

**Conductor resistance at operating temperature:**
```
R_20 = ColdCableCatalogue.resistance_mohm_per_m / 1000  [Ω/m]
α_Cu = 0.00393 per °C  (or 0.00403 per °C per IEC 60228, both acceptable)
T_conductor_op = 0.7 × T_max_conductor + 0.3 × T_site  [approximate operating temp]
  Note: a common engineering approximation for loaded cable; conservative alternative
  is to use T_max_conductor directly.
R_op = R_20 × (1 + α_Cu × (T_conductor_op - 20))  [Ω/m]
```

**Voltage drop formulas (PF = 1.0, reactance term = 0):**
```
VD_4C_volts = sqrt(3) × I_phase_4C × R_op_4C × L_4C_m
VD_3C_volts = 2 × I_phase_3C × R_op_3C × L_3C_m

VD_4C_pct = VD_4C_volts / V_nominal × 100
VD_3C_pct = VD_3C_volts / V_nominal × 100
VD_total_pct = VD_4C_pct + VD_3C_pct

Load_end_voltage = V_nominal - VD_4C_volts - VD_3C_volts
```

Where `V_nominal = ProjectData.voltage`.

For a **direct 1phJB branch** (no 4C trunk, MCB directly to 3C cable):
```
VD_3C_volts = 2 × I_phase_3C × R_op_3C × L_3C_m
VD_total_pct = VD_3C_pct
(no 4C cable exists, no optimization needed)
```

### Step 7 — VD Optimisation for 3phJB Branches (nested discrete search)

Only applicable when `branch_type == '3phJB'` (branch has a 4C trunk to a 3PH JB).
For `1phJB` branches: skip optimisation, go directly to Step 8.

```python
SIZES_4C = [2.5, 4, 6, 10, 16, 25, 35, 50, 70, 95]  # mm²
SIZES_3C = [2.5, 6, 10, 16]  # mm²

# N_out = PowerDistributionBranch.circuit_count  (actual outgoing circuits, 1-3)
# L_4C = resolved 4C cable length
# L_3C = resolved 3C cable length
# I_phase_4C = per_circuit_operating_current_a (balanced assumption)
# I_phase_3C = per_circuit_operating_current_a
# allowable_vd = ProjectData.allowablevdrop

best = None
for size_4c in SIZES_4C:
    row_4c = get_catalogue_row(size_4c, core_count=4, ...)
    if row_4c is None:
        continue
    avail_4c = row_4c.ampacity_a * K_total
    if avail_4c < I_phase_4C:
        continue  # ampacity gate
    if min_size_project and size_4c < min_size_project:
        continue  # minimum cable size gate

    R_op_4c = get_R_op(row_4c, T_conductor_op)
    vd_4c_v = sqrt(3) * I_phase_4C * R_op_4c * L_4C
    vd_4c_pct = vd_4c_v / V_nominal * 100

    if vd_4c_pct >= allowable_vd:
        continue  # 4C alone exceeds budget, no point going further

    for size_3c in SIZES_3C:
        row_3c = get_catalogue_row(size_3c, core_count=3, ...)
        if row_3c is None:
            continue
        avail_3c = row_3c.ampacity_a * K_total
        if avail_3c < I_phase_3C:
            continue  # ampacity gate
        if min_size_project and size_3c < min_size_project:
            continue

        R_op_3c = get_R_op(row_3c, T_conductor_op)
        vd_3c_v = 2 * I_phase_3C * R_op_3c * L_3C
        vd_3c_pct = vd_3c_v / V_nominal * 100

        if (vd_4c_pct + vd_3c_pct) > allowable_vd:
            continue  # total VD exceeds budget

        cost = 4 * size_4c * L_4C + N_out * 3 * size_3c * L_3C

        if best is None or cost < best['cost']:
            best = {
                'size_4c': size_4c, 'size_3c': size_3c, 'cost': cost,
                'vd_4c_pct': vd_4c_pct, 'vd_3c_pct': vd_3c_pct,
                'vd_total_pct': vd_4c_pct + vd_3c_pct,
                'row_4c': row_4c, 'row_3c': row_3c,
                'avail_ampacity_4c': avail_4c, 'avail_ampacity_3c': avail_3c,
            }
        # Do NOT break here — continue searching larger 3C sizes with this 4C
        # only if we haven't found a feasible solution yet.
        # If we already found one, we still continue to check whether the same 4C
        # with a larger 3C gives lower cost (it won't, since larger 3C increases
        # cost and larger 3C is only needed if smaller 3C fails VD).
        break  # Smallest qualifying 3C found for this 4C; no larger 3C will give
               # lower cost for the same 4C, so move to next 4C size.

if best is None:
    sizing_status = 'unsizeable'
    # Add review note: "No cable combination satisfies ampacity and VD constraints.
    # Check allowable VD setting, cable lengths, and available catalogue rows."
else:
    sizing_status = 'selected'
    # Populate result fields from best dict
    # optimization_run = True
    # conductor_volume_proxy = best['cost']
```

Note on the break: once the smallest qualifying 3C is found for a given 4C,
a larger 3C would increase conductor volume and cost while keeping the VD better
(but still within budget). Since we are minimizing cost and the VD constraint is
already satisfied, there is no benefit from iterating to larger 3C for the same 4C.

### Step 8 — Earth Loop / Fault Protection Check

#### 8a. Phase-to-phase fault at remote end of 4C trunk (MCB must trip, GFEP not applicable)

This check applies to 3phJB branches where a 4C trunk cable exists.

```
I_fault_4C = V_line_to_line / (2 × R_op_4C × L_4C_m)
           = V_nominal × sqrt(3) / (2 × R_op_4C × L_4C_m)
  Note: V_line_to_line = V_nominal × sqrt(3) for a 3-phase 400V system.
  The factor 2 accounts for the outgoing phase and return phase conductors in the fault loop.
  Tracer impedance is NOT in this loop (fault is at the 4C cable end, before the 3PH JB).
```

MCB instantaneous trip threshold (from IEC 60898-1):
```
I_instantaneous_min = n_factor × breaker_size_a
  n_factor: B → 5, C → 10, D → 20
  (use the LOWER bound of the range: B=3, C=5, D=10 for conservative pass/fail check)
  Recommended conservative basis: use lower bound (B→3, C→5, D→10).
```

If `I_fault_4C >= I_instantaneous_min`:
  MCB will trip instantaneously (<50ms, well within 0.4s IEC 60364-4-41 limit) → **PASS**

If `I_fault_4C < I_instantaneous_min`:
  MCB may only trip in the thermal region (potentially > 0.4s) → **FAIL**
  Set `fault_protection_4c_status = 'fail'`
  Increase 4C cable size (upsize) until PASS, subject to a maximum of 95mm².
  If still failing at 95mm², set `sizing_status = 'review_required'` and add note:
  "4C phase-to-phase fault current insufficient for MCB instantaneous trip even at
   maximum catalogue size. Check MCB curve selection, cable length, or consult design."

Important: The fault protection check may force a cable size LARGER than the
VD/ampacity result. When this happens, record both the ampacity/VD minimum size
and the final selected (larger) size, with a note that the selection was driven
by fault protection.

```
Trip time reference: IEC 60364-4-41 Table 41.1
  TN system, U₀ = 230V (applies to both 230V 1-phase and 400V 3-phase,
  since the phase-to-earth voltage U₀ = 230V in both):
  Maximum disconnection time = 0.4 seconds.
  Instantaneous MCB trip (<50ms) always satisfies this requirement.
```

#### 8b. Phase-to-neutral fault at end of 3C outgoing cable (MCB + GFEP)

When `gfep_provided = True` (project default):
  GFEP is the primary protection device (trips at 30mA on earth fault).
  The MCB check is a secondary/informational calculation.
  Calculate `I_fault_3C_line_to_neutral` using only the 3C cable impedance
  (exclude tracer impedance — tracer PE-path resistance is not yet in catalogue):

```
I_fault_3C = V_phase / (2 × R_op_3C × L_3C_m)
           = V_nominal / (2 × R_op_3C × L_3C_m)
  Note: V_nominal is phase voltage (e.g. 230V). Factor 2 = L + N conductors.
```

  If `I_fault_3C >= I_instantaneous_min` → MCB secondary check PASS
  If `I_fault_3C < I_instantaneous_min` → set `fault_protection_3c_status = 'review_required'`
    (not a hard fail because GFEP is primary, but noteworthy)

When `gfep_provided = False`:
  The MCB is the sole earth fault protection. Treat the check as a HARD FAIL
  if `I_fault_3C < I_instantaneous_min`. Add a strong review note.

NOTE: Tracer series impedance in the fault loop is deferred to a later pass.
When tracer PE-path resistance data is added to SR/MI catalogues, recalculate
using the full loop: `Z_loop = R_3C_phase + R_tracer_phase + R_tracer_PE + R_3C_N`.
This will give a lower fault current (harder to trip MCB) — the current approach
is therefore non-conservative for the 3C cable check. This limitation must be
documented in the result and user guide.

### Step 9 — Final Cable Selection and Result Assembly

After Steps 3–8:
1. The VD optimisation gives a (size_4C, size_3C) pair.
2. The fault protection check may require upsizing the 4C cable further.
3. The minimum cable size project setting may set a floor.
4. Final selected cable sizes are the maximum of all three constraints.

Populate all `ColdCableResult` fields from the calculation evidence.

Set `sizing_status`:
- `'selected'`: all checks pass
- `'review_required'`: any check produces a warning (e.g., GFEP absent, length assumed,
  fault protection marginal, tracer PE deferred)
- `'unsizeable'`: no feasible solution found

## 6. Cable Length Auto-Trigger

When a user modifies a cable length in the SLD workspace:
1. If the change is for a `Cable4C` or `Cable3C` component
2. The cold cable sizing service (`size_cold_cables_for_project` or equivalent)

3. The result is stored/overwritten in `ColdCableResult`.
4. The cable schedule is updated to reflect the new sizing.
5. The SLD inspector shows the updated cable size annotation.

The trigger point is the existing SLD cable-override save path
(`CableScheduleOverride`). After saving an override, call the cold cable sizing
function for the affected branch.

**No manual "recalculate cold cable" button should be needed for length changes.**
