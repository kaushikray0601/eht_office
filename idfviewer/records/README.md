# idfviewer Records

This folder is the local record book for the `idfviewer` side app.

The app started as an IDF-only viewer, then expanded into a broader engineering model viewer for:

- IDF pipeline isometrics through the custom Hexagon/Isodraft parser.
- PCF pipeline isometrics through the custom block parser.
- IFC reference/model geometry through IfcOpenShell-backed preview parsing.

## Folder Map

- `audit/` - Claude/Codex reviews and independent findings.
- `planning/` - baseline notes, near-term plans, and integration direction.
- `tracking/` - active todo/progress records for this workstream.
- `decisions/` - durable design decisions, including naming and migration choices.
