01 Project Setup & Design Basis Configuration

Defines the engineering design basis for all calculations in the project. All downstream tracer selection, current sizing, breaker choice, and BOQ quantities depend on these values.

Key decisions here: vendor selection, voltage and voltage-variation scenarios, ambient temperature, heat-loss safety factor, maximum breaker size and loading, SR spiral/run limits, RTD/thermostat type, and isolator arrangement.

02 Excel Line List Upload & Validation Input

Upload an .xlsx file (max 10 MB). The module validates mandatory columns, numeric ranges, temperature ordering (Oper_T ≤ Maint_T ≤ Design_T), and detects duplicate rows.

Invalid rows produce a downloadable error workbook with per-row rejection messages. Valid rows enter a Pending state and must be confirmed before calculation proceeds. This protects existing project data from accidental bad uploads.

03 Heat Loss Calculation Thermal

Conduction-based cylindrical heat loss through insulation. The insulation conductivity k is evaluated at the mean insulation temperature using stored polynomial coefficients. Pipe outside diameter is looked up from the ASME B36 table or approximated for non-standard sizes.

Wind correction is applied as a practical project factor (capped at 20%). Heat-loss safety factor (SF) is then applied to give the Design Heat Loss used for tracer selection. Accessory adders (valves, flanges, supports) are calculated using named empirical rules based on pipe OD.

T_mean = (Maint_T + T_amb,min) / 2
k = A·T² + B·T + C (conductivity)
q_base = 2πk(ΔT) / ln((2t+D)/D)
Wind correction factor applied
Design Heat Loss = q_base × SF
Accessory tracer adders (m)
04 SR / MI Tracer Selection Selection

SR path: Catalogue rows are filtered by family, temperature suitability, hazardous-area zone, gas group, temperature class, and voltage compatibility. Power output at Maint_T uses the vendor polynomial. The selector tries 1 → 4 straight parallel runs. Each candidate is ranked by run count, ordered length, and power fit.

MI path (automatic): Triggered when SR catalogue temperature limits are exceeded or when SR cannot meet heat duty within configured run/spiral limits. Only validated MI families are used. The MVP selects identical factory heater sets, with multiple sets allowed where one set under-delivers heat within per-set limits. Each set is independently protected.

Duty ratio = Q_design / (P_LV × N_SR)

05 Electrical Sizing Electrical

Three voltage scenarios are kept separate: low voltage sizes heat delivery, nominal voltage gives the display power output, and high voltage sizes maximum current and breaker.

Circuit count = ceil(I_max_line / (CB_max × CB_loading%) for single-run SR. SR parallel straight runs share one 2-pole MCB per run group in the cold-cable rebuild, while MI heater sets remain independently protected. Breaker size is selected from the standard size table to satisfy the restricted loading factor.

06 Power Distribution & SLD Generation Topology

After breaker sizing, power-distribution branches are built for each line. Branches carry tagged component data: MCBs, 3-phase and 1-phase JBs, cold cables, local isolators, tracers, and end terminations.

The SLD graph is generated from these persisted branches — not from a freehand drawing. Manual topology edits (combine, split, downstream JB) create audit records and can affect cable schedule and BOQ. SLD layout positions are saved separately so recalculation does not destroy manually arranged nodes.

07 Cold Cable Sizing Electrical

Once the SLD topology is committed, the cold cable engine reads every PowerDistributionBranch in the project and sizes the upstream power cable for each feeder segment. Inputs come directly from the confirmed SR/MI results — per-circuit operating current, breaker size, and circuit count — requiring no manual re-entry.

For Distribution JB branches, the engine searches all ampacity-qualified Feeder Cable and Branch Cable combinations and selects the pair that minimises total conductor volume while keeping the complete terminal-path voltage drop within the project limit. For direct Branch JB paths, a single Feeder Cable is sized against the full path current and route length.

Fault protection is verified as a complete single-phase L-PE loop: project source impedance from the three-phase EHT DB fault rating plus Feeder/Branch phase and PE conductor resistance. If an RCD is provided, a marginal MCB instantaneous result becomes Review Required rather than a hard rejection.

K_temp = √((T_max−T_site)/(T_max−T_ref))
K_group from project setup (clamped range)
Derated ampacity = Catalogue_A × K_temp × K_group
VD = 2×I×R(T)×L for single-phase Feeder/Branch paths
Total path VD (Feeder+Branch) + load-end voltage
Distribution JB: min. conductor volume optimisation
L-PE fault loop — source + Feeder/Branch PE path
RCD-aware MCB fault-loop gate
Conductor mass (metric tonnes) per branch

08 BOQ, Cable Schedule & Result Export Deliverables

BOQ is generated per line then consolidated at project level. Items include MCBs, JBs, heating cable (ordered length, including termination allowance), end terminations, RTDs, thermostats, caution labels, isolators, and adhesive tape.

Cable schedule rows are derived from the active SLD topology and the configured DB-to-JB / JB-to-JB length assumptions. Excel exports cover Line Results, Selection Diagnostics, Power Distribution, Alternate Tracers, and MI Selection worksheets.

Selection — Step 4

SR Duty Ratio

Fduty = Qdesign / (PLV × NSR)

Heat-delivery check for straight SR parallel runs. Duty ratio ≤ 1.0 means one full straight run delivers enough heat.

For straight tracing: Fduty < 1.0 does NOT shorten the installed cable. One full run is always installed.

MI — Step 4

MI Resistance–Temperature Correction

RT = R20 × (1 + TCR × (Top − 20))

Heater resistance at operating temperature — drives cold-start vs operating current difference for MI heater sets.

Technology Status

What is implemented, what is MVP, what is planned.

SR Live

Self-Regulating Cable

The default heating technology. Full pipeline from line-list upload through heat loss, tracer selection, electrical sizing, BOQ, cable schedule, and SLD.

  • Straight parallel runs (1–4×)
  • Constructability warnings for small-bore
  • Voltage scenario separation (LV / NV / HV)
  • Selection diagnostics with reason codes
  • SLD inspector evidence per tracer node
  • Vendor curve-point interpolation (roadmap)
  • Override-driven recalculation (roadmap)
MI MVP

Mineral Insulated Cable

Automatic fallback when SR temperature limits are exceeded or no SR heat-duty match is available. Uses validated MI catalogue families only. Multi-set selection for high heat-duty lines.

  • Validated catalogue gate (is_validated flag)
  • TCR-based resistance–temperature correction
  • Multi-set identical heater selection
  • Independent protection per heater set
  • T-class review evidence (not auto-approved)
  • Calculated sheath temperature (roadmap)
  • JB terminal / gland capacity check (roadmap)
CC Complete

Cold Cable Sizing

Sizes upstream power cables from DB/MCC to field JBs and tracer cold ends. Reads directly from the confirmed SLD topology — no manual re-entry of currents or breaker sizes.

  • Temperature derating: K_temp = sqrt((T_max-T_site)/(T_max-T_ref)) — IEC 60364-5-52
  • Derated ampacity = A_catalogue × K_temp × K_group (grouping derating)
  • Conductor R(T) = R₂₀ × (1 + α(T-20)) — IEC 60228
  • VD: 2×I×R(T)×L for single-phase Feeder/Branch paths · PF = 1.0
  • Conductor volume optimisation — minimises copper tonnage by distributing VD budget across Feeder Cable and Branch Cable pairs
  • Series VD check: Feeder + Branch VD ≤ project limit; load-end voltage reported in V
  • L-PE fault loop: EHT DB source impedance + Feeder/Branch phase and PE resistance
  • Source impedance is derived from project DB fault level; final protection studies should verify upstream network assumptions
  • RCD-aware MCB instantaneous sizing gate
  • Conductor mass per branch (metric tonnes) — material takeoff
  • Startup VD over threshold is warning-only and prompts terminal-voltage review, not automatic upsizing
  • Tracer PE-path in earth loop (pending SR/MI catalogue data)
CP Planned

Constant Power Cable

Fixed wattage per metre, independent of temperature — for services where constant heat input is required and self-regulating behaviour is not acceptable. Planned as a fully independent module with its own selection, circuit design, and SLD output.

  • Series-resistance constant-power circuit design
  • Zone-length and power-density matching
  • Parallel and series circuit topologies
  • Mandatory over-temperature protection modelling
  • RTD / thermostat zone control integration
  • CP-specific BOQ, cable schedule, and SLD

SR Selection Diagnostics

Understand every rejection code instantly.

Hover or click any card to flip it and see engineering actions to resolve the issue.

NO_VENDOR_CATALOGUE_ROWS

No catalogue rows for selected vendor

The selected vendor has no usable SR rows in the local database for this project.

Flip for actions

Engineering Actions

  • Confirm the correct vendor is selected in Project Data
  • Check that SR catalogue rows exist in the database for this vendor
  • Verify vendor does not only have CW/MI rows loaded
  • Contact administrator to load missing catalogue data
NO_SR_CATALOGUE_SUITABILITY

No catalogue row passed suitability checks

Rows exist but fail maintain temp, exposure, area class, gas group, or T-class limits.

Flip for actions

Engineering Actions

  • Review Maint_T, Oper_T, Design_T values on the line
  • Check area class and T-class against available catalogue families
  • Confirm catalogue data is correctly loaded (max temp fields)
  • Consider whether MI is appropriate for this temperature range
NO_SR_CATALOGUE_VOLTAGE_COMPATIBILITY

No voltage-compatible catalogue class

No SR row satisfied the voltage compatibility rule — no row rated at or near the project supply voltage.

Flip for actions

Engineering Actions

  • Review project System Voltage setting (Project Data)
  • Confirm vendor catalogue includes the required voltage class
  • Check if a nearby nominal voltage class should be added
  • Tolerance: ±10% of nominal class is allowed
NO_POSITIVE_POWER_OUTPUT

Zero or negative power output at maintain temperature

SR polynomial yields ≤ 0 W/m at Maint_T after low-voltage correction.

Flip for actions

Engineering Actions

  • Review vendor A/B/C polynomial coefficients in the catalogue
  • Verify maintain temperature is within the SR cable's rated range
  • Check catalogue data quality — coefficients may be incorrectly entered
  • Consider MI if maintain temperature is approaching SR limits
NO_SPIRAL_FACTOR_MATCH

No run count satisfies duty ratio limit

Even at the max configured parallel runs, no SR candidate delivers enough heat per run.

Flip for actions

Engineering Actions

  • Review Max SR parallel runs setting (currently 1–4)
  • Consider allowing spiral wrap if project practice permits
  • Review heat-loss safety factor — reduce if justified
  • Consider a higher-output tracer family or different vendor
  • Review insulation thickness and basis
TRACER_SELECTION_ERROR

Unexpected engine error

The SR selection engine encountered an unexpected exception during evaluation.

Flip for actions

Engineering Actions

  • Check line data for unusual or missing values
  • Check catalogue data for null or malformed fields
  • Review server logs for the specific exception
  • Escalate to application maintainer if it persists
